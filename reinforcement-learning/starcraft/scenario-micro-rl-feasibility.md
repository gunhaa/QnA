# 짧은 시나리오 단위 RL(마이크로 컨트롤)은 얼마나 할 만한가 — 스타크래프트 기준

> 조사 기준일: 2026-09-21. 풀게임 학습 비용은 [RTS RL 학습 비용·난이도](./starcraft-rl-bot-training-cost-and-difficulty.md) 참고.

## 쉬운 설명

전체 게임을 배우게 하는 건 "30분짜리 시험을 수백만 번 보게 하는 것"이라 힘들어요. 그런데 **"마린 5기 vs 저글링 6마리, 1분 안에 끝"** 같은 문제만 떼어내면? 한 판이 1분이니 수백만 판도 금방이고, 잘했는지 못했는지도 바로 알 수 있습니다. **그래서 이건 GPU 한 장으로 며칠이면 됩니다.** 실제로 연구도 대부분 여기서 시작했어요.

## 일반 설명

### 0. 결론

**할 만합니다. 난이도 ★★★☆☆, 개인 + GPU 1장 + 수일~수주.** 풀게임 대비 비용이 두 자릿수 배 차이 납니다. 근거가 되는 공개 사례:

| 사례 | 규모 | 자원 |
|---|---|---|
| **Gym-μRTS (MicroRTS-Py)** | 경량 RTS **풀게임** SOTA 에이전트 | **GPU 1장 + vCPU 3개 + RAM 16GB로 약 60시간** |
| **SMAC / SMACv2** (SC2 협동 마이크로 벤치마크) | 시나리오 1개 학습 | MAPPO/QMIX 기준 V100 1장 **36~48시간/런** |
| **PySC2 미니게임** (MoveToBeacon, DefeatRoaches 등) | DeepMind 공식 소과제 | 공개 베이스라인·재현 코드 다수 |

즉 **"1분짜리 시나리오 RL"은 이미 학계의 표준 입문 과제**이고, 인프라·코드가 전부 공개돼 있다.

### 1. 왜 갑자기 쉬워지는가 — 다섯 가지가 동시에 완화된다

| 항목 | 풀게임 | 1분 시나리오 | 효과 |
|---|---|---|---|
| **에피소드 길이** | 약 4,800스텝 (20분, 6프레임/스텝) | **100~300스텝** | 신용 할당 거리가 **20~40배 단축** |
| **보상 밀도** | 마지막에 승/패 ±1 하나 | 가한 피해·받은 피해·킬·생존을 **매 스텝 shaping 가능** | 희소 보상 문제 사실상 소멸 |
| **행동 공간** | 건설·경제·테크·정찰·전투 전부 | **이동 + 공격(+ 타깃 선택)** | 자기회귀 복합 행동 헤드 불필요 |
| **관측 공간** | 전맵 + 안개 + 기억(POMDP) | 국소 전장, 유닛 수 고정, 대개 완전관측 | LSTM/기억 구조 없이도 학습됨 |
| **상대** | 자가대국 필수 → 비정상성 | **고정 스크립트/내장 AI** | 환경이 정상(stationary) → 학습 안정, 리그 불필요 |

풀게임 RL을 어렵게 만드는 요인 목록에서 **희소 보상, 장기 신용 할당, 부분 관측, 자가대국 비정상성이 한꺼번에 빠진다.** 남는 건 평범한 PPO 과제다.

### 2. 처리량 산수

1분 에피소드(BW 기준 약 1,440프레임, 6프레임/스텝이면 약 240스텝)를 가정하면:

- 유닛이 10~20기뿐이라 게임 연산이 가볍고 **헤드리스 배속이 잘 나온다**(풀게임보다 유리).
- 배속 30배 × 동시 16게임 = 실시간 대비 480배 → **하루 약 69만 에피소드**.
- 마이크로 과제는 보통 **10만~수백만 에피소드**면 수렴한다 → **하루~수일**.

풀게임이 "수백만 판 × 20분"이라 수개월인 것과 정확히 대비된다. 같은 알고리즘, 같은 코드, **에피소드 길이만 20분의 1이 된 것이 전부인데 비용이 자릿수로 갈린다.**

### 3. 구현 경로 세 가지

| 경로 | 내용 | 장점 | 단점 | 추천도 |
|---|---|---|---|---|
| **A. BW + BWAPI 직접** | [TorchCraftAI 마이크로 시나리오 튜토리얼](https://torchcraft.github.io/TorchCraftAI/docs/microtut-intro.html)이 공식 예제를 제공. 동종 유닛 미러 매치, 공중/지상 매치, `hugmiddle`(중앙 점령) 같은 비전투 과제까지. 행동은 **공격/이동 확률분포 + 20×20 그리드 위치**, 예제는 Evolution Strategies 사용 | 진짜 브루드워. 결과를 실제 봇에 바로 이식 가능 | 환경 인프라 고생이 여전. 유닛 스폰은 **커스텀 맵(트리거)** 또는 프레임워크 기능으로 해결해야 함 | 목적이 BW라면 ★★★ |
| **B. SC2 + PySC2 미니게임 / SMACv2** | DeepMind 공식 미니게임 7종, SMAC 계열 협동 마이크로 벤치마크 | 공식 지원, 베이스라인·논문·코드 풍부. 바로 시작 가능 | SC2이므로 BW와 유닛/물리가 다름 | 학습이 목적이면 ★★★★ |
| **C. MicroRTS (MicroRTS-Py)** | 초경량 RTS. 2026 IEEE WCCI **MicroRTS LLM Game AI 대회**도 진행 중 | 가장 빠르고 싸다. **1 GPU 60시간에 풀게임 SOTA** | 스타크래프트가 아님 | 입문·파이프라인 검증용 ★★★★★ |

**권장 순서**: C 또는 B로 RL 파이프라인(관측 인코딩 → PPO → 평가 자동화)을 먼저 완성하고, 검증된 코드를 A로 이식한다. 처음부터 BW에 붙이면 "알고리즘 문제인지 BWAPI 문제인지" 구분 못 해서 시간을 태운다.

### 4. 시나리오 설계 실무 체크리스트

**보상**
- 기본형: `(가한 피해 − 받은 피해)`를 정규화해 매 스텝 지급 + 전멸 승리 보너스 + 시간 페널티.
- **킬 수만 주면 과도하게 공격적인 정책**이 나온다. 받은 피해 페널티가 있어야 카이팅·후퇴가 나온다.

**초기 상태 랜덤화 (가장 중요)**
- 유닛 위치·수·체력을 매 에피소드 랜덤화하지 않으면, 에이전트가 관측이 아니라 **타임스텝만 보고 정답 시퀀스를 외우는 개방루프(open-loop) 정책**을 학습한다. 실제로 원조 SMAC이 이 문제로 비판받아(타임스텝만 조건으로 해도 상당한 승률이 나옴) **SMACv2가 유닛 종류·위치·수를 랜덤화하는 방향으로 개정**됐다. 남의 실패를 그대로 반복할 필요는 없다.

**커리큘럼**
- 3v3 → 5v5 → 혼합 유닛 순으로 난이도를 올리는 전이학습이 효과가 검증돼 있다(StarCraft Micromanagement with RL and Curriculum Transfer Learning).

**종료 조건 / 평가**
- 한쪽 전멸 또는 타임아웃(1분). 평가는 **고정 스크립트 상대**(기본 어택땅, 단순 추격 AI) 대비 승률 + 남은 체력 총합으로 한다. 학습 곡선만 보면 속는다.

### 5. 어디까지 기대할 수 있나

**나오는 것** (모두 기존 연구에서 재현된 것들)
- **카이팅** — 벌처 vs 질럿처럼 사거리·속도 우위가 있으면 공격-후퇴-공격이 자연 발현
- **집중 사격(focus fire)** — 한 대상에 화력을 몰아 적 수를 빨리 줄이는 행동
- **부상 유닛 후퇴 후 재진입**, 진형 유지, 좁은 길목 활용

**안 나오는 것**
- **시나리오 밖 일반화.** 5v5 마린저글링용 정책은 탱크가 끼는 순간 무너진다.
- **상위 판단.** "이 교전을 할지 말지, 언제 후퇴할지"는 시나리오 안에 없다. 실제 봇에 붙이려면 **"언제 이 정책을 호출할지" 정하는 상위 정책**(계층적 RL 또는 기존 스크립트 봇의 전략 모듈)이 따로 필요하다.

이 격차가 Pluto와의 진짜 차이다. Pluto는 마이크로와 매크로를 **한 네트워크가 통합**해서 푼다. 시나리오 RL은 그 부품 하나를 잘 만드는 일이고, 부품을 아무리 모아도 자동으로 통합되지는 않는다. 다만 **기존 스크립트 봇의 전투 모듈만 RL로 교체**하는 하이브리드는 매우 현실적이고, 실제로 여러 대회 봇이 이 방향을 취해 왔다.

### 6. 개인 기준 현실적 일정

| 주차 | 할 일 | 완료 기준 |
|---|---|---|
| 0~1주 | 환경 연결, 랜덤 정책으로 에피소드 자동 반복 | **초당 스텝 수(FPS) 측정치 확보**, 1,000 에피소드 무중단 |
| 1~2주 | 관측·보상 설계, 첫 PPO 학습 (동종 5v5 미러) | 무작위 정책 대비 승률 유의미 상승 |
| 3~4주 | 초기 상태 랜덤화 + 커리큘럼 | **고정 스크립트 상대 승률 60%+** |
| 5~8주 | 유닛 조합 확장, 기존 봇의 전투 모듈로 접속 | 스크립트 전투 모듈 대비 교전 승률 개선 |

**1~2개월이면 눈에 보이는 결과가 나온다.** 풀게임(1년+)과 자릿수가 다르다. 다만 이 스코프에서도 **시간의 절반 가까이는 여전히 환경 인프라**에 들어간다는 점은 각오해야 한다 — 규모가 풀게임의 1/10일 뿐이다.
