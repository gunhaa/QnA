# 파운데이션 모델 vs LLM, 뭐가 달라요?

파운데이션 모델(Foundation Model)은 "큰 장난감 상자"예요. 그 안에는 글자를 다루는 장난감(LLM), 그림을 보는 장난감(VLM, Vision-Language Model), 소리를 듣는 장난감(Audio FM)이 다 들어있어요.

**LLM(Large Language Model, 대규모 언어 모델)**은 그 상자 안에서 "말하기 장난감"만 골라낸 거예요. 글자를 아주 많이 배워서 글을 읽고 쓰는 걸 잘해요. (예: Claude, GPT, Gemini)

**한 줄 정리**
- 파운데이션 모델 = 큰 상자 (그림도, 소리도, 글도 다룰 수 있음)
- LLM = 상자 안의 "글 담당" 장난감 하나

그래서 "모든 LLM은 파운데이션 모델이지만, 모든 파운데이션 모델이 LLM은 아니에요."
